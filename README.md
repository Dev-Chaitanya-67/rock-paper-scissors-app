# Rock Paper Scissors Game

A classic web-based Rock Paper Scissors game developed using HTML, CSS, and JavaScript.

## 🎮 Features
- **Interactive Gameplay**: Play Rock, Paper, or Scissors against a computerized opponent.
- **Score Tracking**: Keeps track of wins, losses, and ties.
- **Responsive UI**: Clean and intuitive styling for an engaging experience.

## 📁 Project Structure
The project is built with a standard and clean web development structure:
- `game.html`: The main web page structure.
- `Scripts/game.js`: The central game logic and DOM manipulation.
- `Styles/game.css`: Cascading style sheets for styling and layout.
- `icons/`: Directory containing various graphical icons used in the UI.

## 🚀 How to Run
It's incredibly simple to start playing:
1. Clone or download this repository to your local machine.
2. Open the `game.html` file using any modern web browser (e.g., Chrome, Firefox, Edge, Safari).
3. Start playing and have fun!

## 🛠️ Technologies Used
- **HTML5**: For crafting the basic structure of the interface.
- **CSS3**: For adding visual appeal, layouts, animations, and responsive design concepts.
- **JavaScript (Vanilla)**: For executing the core game logic, randomizing choices, and updating UI elements dynamically based on user interactions.
